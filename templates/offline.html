Qué significa y qué revisar

El navegador no recibió ninguna respuesta del servidor: la solicitud no llegó o la conexión se cortó. Esta página la muestra el propio navegador, así que el servidor no tiene registro de este intento.

  • «Red del dispositivo: sin red»: el problema es la conexión del dispositivo (wifi, datos móviles, modo avión).
  • «Red del dispositivo: conectada»: el dispositivo tiene red pero no llega al sistema. Pruebe abrir otro sitio; si otros sitios funcionan, revise el DNS del dominio, el firewall de la red institucional y que Nginx esté activo (systemctl status nginx).
  • Si el servidor responde pero el sistema no, el navegador mostraría el error 502 o 504 en lugar de esta página.
